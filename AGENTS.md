# Notes for AI coding agents

- Start with [README.md](README.md), then follow [doc/code-convention.md](doc/code-convention.md).
- The why of the project (the rubric, the decisions, the next phases) is in [doc/analysis.md](doc/analysis.md).
- Before adding a request to another host, an asset from a CDN, an embed, an analytics tool, or anything kept in the browser (cookies, storage), read [doc/code-convention.md#the-privacy-page](doc/code-convention.md#the-privacy-page): the privacy page must change in the same commit.
- Adding or changing a framework is an edit to `data/frameworks.json` or `data/adjacent.json`; `pnpm run test` checks it against the rubric.
- Navigation keeps the URL a thin wrapper around the destination: only the URL writer (`urlWriterOf` in `src/util/url.ts`) writes the URL, from the destination after a step, and only `src/common/util/browser-history.ts` touches `window.history`, `location` or `navigation` (ESLint refuses it elsewhere). A link or a view only dispatches its message (`Navigate`), never pushes a URL or saves a scroll itself, even to work around a browser. Read [Navigation and the URL](doc/code-convention.md#navigation-and-the-url), [The screen stack](doc/code-convention.md#the-screen-stack) and [No update wrapper (and the URL exception)](doc/code-convention.md#no-update-wrapper-and-the-url-exception) before changing a move, the URL or the scroll.
